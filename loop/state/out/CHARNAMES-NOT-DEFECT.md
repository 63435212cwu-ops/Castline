# 纠正：「characters 里含原文 0 次的名字」**大多不是缺陷**

**版本**：`f6a657935c945a3a9bcfc000` · 方法：归一化索引 + 原文语境逐条读

---

## 一、我先前怀疑过这一批，本轮**逐条核实后推翻了自己的怀疑**

判据：「`characters` 里的名字在原文出现 **0** 次」⇒ 疑似错名。
当前满足的：**21 个名字、36 条事件引用**。

**逐条读原文后，绝大多数是**合法的**：**

## 二、我为什么先前会怀疑（这次的教训在哪）

我的判据是「**原文出现 0 次**」。而这条判据的问题是：

> **它把「原文出现次数少」与「原文不存在」混为一谈，而且我的计数用的是**精确串匹配**。**

- `黄莲道长`（带「道长」）在原文 0 次 —— 但**「黄莲」有 3 次**（原文写的是「胸口绣着黄莲」）
- 于是我的判据**误报**了。

**⇒ 正确做法**（我这次做的）：
**先剥离「称谓后缀」（道长/先生/门主…）再数**，或**直接读原文语境** ——
**而不是拿完整串去 `count()`。**

## 三、与「钟丽 / 许玉春」的区别（那两条是真的）

| 案例 | 错名原文次数 | 正名原文次数 | 性质 |
|---|---:|---:|---|
| **钟丽** | **1**（原文自身笔误） | 钟璃 **588** | ✅ **真错名**（已修 129 条） |
| **许玉春** | **0** | 李玉春 **295**（且 43 条引文逐字写「李玉春」） | ✅ **真错名**（已修 92 条 + 角色表） |
| 黄莲/绿莲/红莲道长 | 3 / 1 / 20（作为「X莲」） | — | ❌ **非错名** |

**⇒ 判据的可靠形态是「错名几乎不出现 **且** 有一个高频的近似正名」，**
**而不是「错名不出现」单条。**

这正是我在第 34/35 轮已经用过的判据（**倍数条件**），
**而本轮我一开始退回了单条判据（出现 0 次），于是误报。**

## 四、沉淀规则（第 33 条）

> **我刚刚修好的判据，换个场景就退化了 —— 因为新场景的"0 次"含义不同。**
> - 在「钟丽/许玉春」场景：名字是**人名**，`count()` 精确匹配成立。
> - 在「黄莲道长」场景：名字是**称谓 + 颜色号**，原文写的是**不带称谓的形式**（「胸口绣着黄莲」）。
> **⇒ 同一条判据（"原文 0 次"）在两种场景下含义不同：**
> 前者的 0 次 = **不存在**；后者的 0 次 = **写法不同**。
> **⇒ 复用判据时必须重新验证它在**新场景下的含义**，不能因为"上次它管用"就直接套用。**
