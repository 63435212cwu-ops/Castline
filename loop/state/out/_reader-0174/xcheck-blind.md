## 因果

1. **暗子被拔除 → 魏渊确实不知皇后生病 → 只能答"近来公务繁忙，不知皇后病了" → 皇后误会他知而不来**。
   机制：情报渠道被皇帝从物理上掐断，魏渊失去"皇后患病"这一信息，无从据此作答或解释；而当众说明等于暴露自己曾在此布暗，所以只能吞下误解。
   引文A：`因为安插在附近的暗子，前段时间被元景帝拔除。而皇后并不知道此事。` [628592,628624)（该句以 `他确实不知道皇后生病了，` [628580,628592) 起头）
   引文B：`这些事儿，不可能当众说出口，便只能任由皇后误会。` [628630,628654)

2. **皇后厌食 = 没胃口 ＋ 吃腻宫廷菜 → 鸡精只需解决"味觉疲劳"这一环即可奏效**。
   机制：叙述者把厌食拆成两个原因，其中一个恰是调味品能作用的变量；所以提鲜成功直接带来食量恢复，而不是靠"病好了"。
   引文A：`皇后吃惯了宫里的珍馐美味，厌食除了自身没胃口，吃腻宫里的菜也是一个原因。` [630302,630338)
   引文B：`她们已经试过了，味道与众不同，令人难忘。` [630633,630653)

3. **鸡精提鲜百倍 → 皇后"停不下来"地喝完汤 → 次日卯时刚过皇后宫里的太监就来打更人衙门送礼**。
   机制：强烈的味觉刺激先造成"咽下去"这一生理反射，再转成主动索食（盛饭），可观测的进食行为成为赏赐的依据。
   引文A：`强烈的鲜味在味蕾间炸开，咕噜...修长的脖颈里，喉咙滚动，下意识的就咽了下去。` [630766,630805)
   引文B：`次日，卯时刚过，皇后宫里的太监带着一批金银玉器来到打更人衙门。` [630894,630925)

4. **魏渊与皇后宫宦官有旧 → 魏渊当面追问、宦官给出细节 → 魏渊"由衷的笑了"**。
   机制：老相识关系决定了他不必以公事口吻寒暄，可以直接索取"吃了多少"这类近身数据；数据的确定性是他放心的原因。
   引文A：`魏渊在浩气楼接见了宦官，这位明显与魏渊是老相识的公公，随意的坐在桌边` [630931,630965)
   引文B：`魏渊盯着他，有些紧张的问：“没有厌食？吃了多少。”` [631021,631046)

5. **魏渊把瓷瓶留给自己、让许七安从罐里倒一部分 → 罐子在他手里被分装过 → 与怀庆"是半罐"的说法接得上 → 但"半罐"是否源于这次分装，原文没写**。
   机制：交接动作本身改变了容器内的存量，使"罐内到底剩多少"成为一个只有经手方才知道的量；这个量恰好是许七安那句"满满一罐"的可证伪点。
   引文A：`魏渊摇摇头，没接，看着罐子：“瓶子里是留给你的，那才是我的。”` [630422,630453)（人物话）
   引文B：`可本宫听说，魏渊送到母后那里的...鸡精，是半罐。` [631586,631611)（人物话）
   *注：A 是人物话，只能证明"当天罐里被倒出一部分"；"送进宫的就是半罐"以及"半罐来自这次分装"都是我的推断，不是原文陈述。*

## 我发现的遗漏风险

1. **"小铜锣"就是许七安本人的身份称谓**（不是道具铜锣）。`确认小铜锣没有被自己捧上来的面毒死` [630041,630058)——同章前面魏渊派去传话的人写的是"一个骑马的铜锣" [629315,629322)，同一章内以同一称谓指两类人（魏渊的贴身铜锣 vs 许七安），极易误判为器物或误并成同一人。
2. **怀庆公主有自己的"府上侍卫"**：`怀庆便省的让府上侍卫多跑一趟` [629037,629051)——她使唤的不是宫里的人而是"府上"的人，是她有独立府邸编制这一事实的唯一落点，容易被当作闲笔漏掉（"是否已出阁"本章没说，不推）。
3. **"裱裱"是许七安对临安公主的私下称呼，本章从未与"临安"同句直连**。`他得给裱裱留着。` [631390,631398) 与 `在临安公主心里，许七安早已弃暗投明，成了她麾下的马仔。` [631543,631570)——若只读前半段会不知道"裱裱"是谁，注人名时极易漏映射。
4. **许七安私留的一小瓶鸡精，与"给褚采薇留了一小瓶"是两笔账**。`他只给褚采薇留了一小瓶鸡精。` [629690,629704) 与 `他其实是有的，还有一小瓶` [631370,631382)——"一小瓶"在本章出现两次指不同归属，数量核对时极易合并成一份。
5. **怀庆当面用了"改良"二字**：`你那配方似乎有所改良？` [631236,631247)，而许七安归功于宋卿与褚采薇 `都是宋师兄和采薇姑娘的功劳。` [631262,631276)——暗示宫中吃到的版本与早前版本不同，但全章没交代改动内容，是个隐藏的技术信息差。
6. **时间密集且互不重叠**：`一刻钟的时间后，许七安捧着一碗鸡蛋肉丝面回来` [629944,629966)；`黄昏。` [630487,630490)；`次日，卯时刚过` [630894,630901)；`午后刚过` [631117,631121)。四个时间点若漏掉"次日"，会把赏赐误记成当天。
7. **魏渊的生理反应是本章少见的"失态"标记**：`魏渊的眼睛猛的亮起。` [630238,630248)——与他此前"怒道：滚出去"却不真怒的定性 `魏渊是个不会真正发怒的人` [630142,630154) 形成对照，注情绪状态时容易只用后者。
8. **宋廷风捐了"足足五两银子"给养生堂** [629197,629228)，而这一信息被叙述者用来说明许七安为何要请他——钱数与人情链都很容易在摘要里被抹掉。

## 前后矛盾或悬念

1. **满罐 vs 半罐（本章核心矛盾，且是章节收尾的悬念）**
   - 许七安：`“没了。”许七安立刻摇头：“满满一罐都给了魏公，送去了皇后娘娘那里。”` [631329,631364)（人物话）
   - 怀庆：`可本宫听说，魏渊送到母后那里的...鸡精，是半罐。` [631586,631611)（人物话）
   - 收尾未解：`怀庆也看着他，两人不由的沉默了。` [631639,631655)（章节到此结束，原文未给解释）
2. **魏渊到底知不知道皇后生病（叙述与人物话之间有张力，未解释）**
   - 叙述层给出"确实不知道"的理由：`他确实不知道皇后生病了，因为安插在附近的暗子，前段时间被元景帝拔除。` [628580,628614)
   - 但他当着怀庆说的却是"听说身体有恙"：`陛下听说皇后食欲不佳，身体有恙，让我代他过来探望。` [628787,628812)（人物话）——"听说"与叙述层的"确实不知道"来源不明；且这句把生病说成"食欲不佳、身体有恙"，与元景帝转述给魏渊的原话 `“陛下说皇后近来食欲不佳，让微臣过来瞧瞧。”` [628261,628283)（人物话）措辞并不一致，原文未解释差别。
3. **怀庆说"母后却吝啬的不给"** [631305,631318)（人物话）**与"皇后食欲恢复、破天荒问午膳"** [631075,631097)（人物话）并置——食欲恢复与"舍不得分给女儿"之间没有解释，也无从判断是皇后真吝啬还是鸡精存量不足。
