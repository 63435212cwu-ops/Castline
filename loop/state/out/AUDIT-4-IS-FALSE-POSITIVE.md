## 二、逐字验证（这是决定性的）

原文那一句：
```
'…奴婢看到，与塔姆拉哈密谈者...”'
```

**逐字比对**：
```python
seg = text[i:i+6]              # '塔姆拉哈密谈'
'塔姆拉哈' + '密谈'            # '塔姆拉哈密谈'
seg == '塔姆拉哈'+'密谈'       # **True**
```

**⇒ 原文是「与塔姆拉哈**密谈**者」。**
- 「**塔姆拉哈**」是那个客人的名字（4 字，原文 **9** 次）
- 「**密谈**」是动词（"偷听了一场密谈" —— **同一段上文刚刚写过这个词**）
- **「塔姆拉哈密」不是名字，是「塔姆拉哈」+「密」的**假边界**。**

**上下文自证**：前一句是
> 「某天夜里，她无意中偷听了一场**密谈**，听到了"火炮"、"器械"等字眼…」

## 四、**我的扫描犯了同一个错**（这点更重要）

我在第 46 轮说「我独立复现了第 4 条（`塔姆拉哈密` 1 次 vs `塔姆拉哈` 9 次），

**⇒ 那句话是错的。我的"复现"复现的是**审计的分词错误**，不是缺陷。**

## 五、这对"近形错名"这一类缺陷的影响（我必须回收一部分结论）

我先前报过 3 例已修：
| 案例 | 是否成立 | 依据 |

| 钟丽 → 钟璃 | ✅ **成立** | 588 : 1，且「钟丽」出现在**独立句首**（「"钟丽，你晋升四品的契机到了。"监正悠悠道。」） |
| 许玉春 → 李玉春 | ✅ **成立** | 295 : 0，且 43 条**引文逐字**写「李玉春」 |

| **塔姆拉哈密 → 塔姆拉哈** | ❌ **不成立** | **假边界**（4 字名 + 动词「密谈」） |

**⇒ 3 例成立、1 例是我误报。**
**⇒ 区别在于**前 3 例我读了**独立语境**（句首、逐字引文、角色表冲突），

## 六、沉淀规则（第 43 条）

> **`count('ABC')` 不能证明「ABC 是一个词」—— 它只证明「这三个字相邻出现过」。**
> 我（和审计）都把「塔姆拉哈」+「密谈」读成了「塔姆拉哈密」+「谈」。
> **⇒ 判据必须加一道**边界校验**：候选前后**紧邻的字**是否构词
> （如「密」紧跟「谈」⇒ 是「密谈」，不是名字的一部分）。
>
> **更一般地**：我在第 47 轮说「近形错名只能产出候选」，
> 而这一轮我**自己在第 46 轮就违反了它** —— 我把一个 `count()` 结果当成了"独立复现"。
> **⇒ 规矩要落在流程上**：任何"疑似错名"在写入报告前，**必须先打印它前后的原始字符**。
> 这一条可机械执行，不依赖我记得。

## 八、边界校验的**可执行形式**（写进流程，不依赖记性）

```python
# 任何"疑似错名"在写入报告前必须先跑这一步
import re
for m in re.finditer(candidate, text):
    p = m.start()
    print(repr(text[max(0,p-25) : p+len(candidate)+25]))
# 人工判据：候选的**后邻字**是否与候选末字构成常用词
#   如 候选'塔姆拉哈密' + 后邻'谈' ⇒ 「密谈」是词 ⇒ 候选是假边界
#   如 候选'钟丽' + 后邻'，' ⇒ 标点 ⇒ 独立成词
```

**⇒ 这一步把「`count()` 结果」升级为「带语境的证据」，
而它**不依赖我记得某条规则** —— 它是输出格式的一部分。**

```

```

**原文（该事件紧邻上文）逐句对照 summary**：

| summary 说 | 原文原文 |
|---|---|
| 「张婶」 | `"我让**张婶**帮我洗了。"` |
| 「浆洗衣裳」 | `"我见她实在拮据，就让她帮我**浆洗衣裳**，多付两成的铜钱。"` |

**⇒ 这不是"summary 编造"，而是"审计的关键词回查范围太窄"，
它在一个**不含该场景**的窗口里搜，于是搜不到。**
