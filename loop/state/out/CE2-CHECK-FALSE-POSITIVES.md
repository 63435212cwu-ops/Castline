## 一、我的判据

CE2 的形态是：`states[].before` 与 `after` **共用同一条引文** ⇒ 怀疑"前后值相同、没承载变化"。

**机械化**：若 `before` 与 `after` 各自的引文**偏移集合完全相同** ⇒ 报警。

**结果：全 41 个候选里命中 3 处。**

## 二、逐条核实 —— **3 处全部不是缺陷**

### ① `read_sanguo_L1_0001` states[14]（孙坚官职）

```
共用引文原文:
'是夜，十常侍即于狱中谋杀之；假帝诏以孙坚为长沙太守，讨区星，不五十日，报捷，
 江夏平，诏封坚为乌程侯。'
before = 由十常侍假帝诏授为长沙太守
after  = 讨区星报捷，诏封乌程侯
```

**⇒ 这一句话本身同时包含前后两态**（「授为长沙太守」→「诏封乌程侯」）。
**⇒ 一条引文**合法地**支撑两次状态 ⇒ 共用偏移是**正确**的，不是缺陷。**

### ② `read_dafeng_L3_0027` states[8]（许新年）

```
before = 勒住马缰，不漏痕迹地审视堂兄。
after  = 微微松口气，深深作揖向老师与慕白先生道谢；把致谢对象放在两位大儒…
```

```
after  = 听到口信后仍是想不起来；本单元结束时没有变化。
```
**⇒ 这条**本身就明确写了「没有变化」** ⇒ 共用同一条引文是**恰当**的（它就是"无变化"的证据）。**

## 三、我的判据错在哪（第 4 次同类）

**「before/after 共用引文」不等于「前后无变化」，因为：**

| 情形 | 共用引文是否合理 |
|---|---|
| 一句话里写了两个时点的事实（①②） | ✅ **合理**（引文覆盖了变化的前后） |
| 状态确实**没有变化**，引文就是"无变化"的证据（③） | ✅ **合理** |
| 前后值**逐字相同**且引文只支持其中一态 | ❌ 才是 CE2 缺陷 |

**⇒ CE2 的真正定义是「`before.text` 与 `after.text` **语义相同**」或「引文**只**支持其中一态」——
前者需要语义判断，后者需要"引文能否推出该字段"的推理。
**我的"偏移集合相同"只是一个**语法线索**，与定义隔了两层。**

# 七、第 5 次尝试：查「断言里的引语是否在其自带引文里」→ **47 处又全是压缩引用**

## 判据与结果

**判据**：断言字段里 `“…”` 形式的引语，若不在该条自带引文里 ⇒ 报警。

| 步骤 | 结果 |
|---|---|
| 初筛 | **57** 处 |
| 去掉**仅标点/引号差异**（`core()` 后相同） | 剩 **47** 处 |
| 逐条读原文核实 | **47 处全部为「压缩引用」，非编造** |

## 实例（`read_dafeng:L1:0001` tasks[4]）

```
断言里写的引语：  『沿途二十里没有妖气、岸边没有痕迹』
原文原句：        『"我的人说，沿途二十里，没有在河内观测到妖气，岸边也没有痕迹。"』
                  ↑ 就在**同一条的 evidence 数组**里，逐字存在
```

**⇒ 断言把原文的「**没有在河内观测到**妖气」压缩成「**没有**妖气」——
语义未变、且**完整原句就在它自己的 evidence 里** ⇒ **不是编造，是压缩引用。**

## 我漏在哪个环节（这次很具体）

**我的提取器**只读了 `it['text']/['result']/['action']…` 这类**字符串字段**里的引号引语，
**没有把引语与「该条 evidence 里的完整原句」做**同义比对**。**
而这两者的关系是「**压缩 / 展开**」，不是「相等 / 不等」。

**⇒ 判据问的是「是否逐字出现」，而缺陷的定义是「是否有出处」——
问题层级又错了一层（第 5 次）。**
