## 三、②的那 1 处**是真错**（第 30 轮我也找到过它）

```
字段：read_dafeng:L1:0005 → /selfCheck/crossRangeQuotes[0]
quote = '两日前，许七安在牢内嚷嚷着要见府尹，说有重要线索汇报，随后府尹大人就破案了。按照'（40 字）
声明 = start=18862, end=18924  ⇒ 跨度 62
原文 find(quote) = 18862          ⇒ start 对
原文 [18862:18902] == quote       ⇒ quote 与原文逐字一致
⇒ **end 写错 22**（end 应为 18902，写成 18924）
```

**⇒ 这是"声明长度与引文长度不一致"的机械确证实例。**
**⇒ 它与第 56 轮那处（`notAnchored[3]` 的 start 错）属同一族：**偏移字段与引文不自洽**。**

## 四、把这一族写成**同层判据**（第 51 条要求的形式）

| 项 | 内容 |
|---|---|
| **① 应当成立什么** | 引用条目的 `quote` 与它的 `start`/`end`（或 `startAbs`/`endAbs`）**自洽**：切片等于引文，或长度等于引文长度 |
| **② 实际缺了什么** | 切片 ≠ 引文，且**没有任何一组偏移能对上** |
| **③ 为什么是问题** | 读者/下游按该偏移回原文会**落到错误的文字上**；且这是"引文与坐标不一致"，**不能靠指代或压缩解释** |
| **判据是否同层** | ✅ **同层**（都是"两个值是否相等"） |
| **能否举出反例** | ❌ **不能**（若两组偏移都不对，不存在合理解释） |

**⇒ 该判据满足第 51 条的三要素与第 48 条的"举不出反例"。**
