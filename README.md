# Castline · 小说星图

把一部小说的任意材料（大纲 / 细纲 / 正文 / 人物设定 / 未完稿）丢进来，模型通读全部文字，识别角色、归并别名、建档八维属性（含推断依据）、剧情点、明线 / 暗线关系与主线 / 支线，然后把整部书画成一片星空。

## 启动

```bash
cd 星系
python3 -s serve.py 8000
open http://127.0.0.1:8000
```

第一次打开会要求接入 API（右上「工具 → API」）：档案 = 名称 / 协议（OpenAI 兼容 `/chat/completions` 或 Anthropic `/v1/messages`）/ 接入地址 / 模型 / 密钥，可增删改、切换、测试连通；保存在 `data/llm-config.json`。也会自动导入 `~/.nest-drama/api-config.json` 与环境变量 `LLM_BASE_URL / LLM_MODEL_NAME / LLM_API_KEY`、`ANTHROPIC_API_KEY`。

## 一片星空，三种图谱

| 图谱 | 进入 | 看什么 |
|---|---|---|
| **星座**（主画面） | 打开作品即是 | 全部角色都是星，按分组排成一张平面天球：主角团居盘心；其余每个分组一个扇区，12 点起顺时针；团名写在扇区外缘。星的亮度与光芒 = 咖位，星色 = 所属分组；每个分组一团星云，星云的形状就是这组成员所在的范围（势力范围）。组内核心星连成星座线；组间联系汇成束丝（从星出发、经两端轮毂拱离盘面，斜着看是一道道光拱），默认只亮最强的一批（大书约 40 束），主角团与各团的联系是盘心照出的光束。悬停一颗星 → 星外荡开两圈涟漪，它的全部组间联系亮起，它和有联系的星保持全亮、其余压暗，并出角色卡；悬停团名 → 该团星云提亮、成员点亮、该团的联系亮起，并出团卡。顶栏切换分组：阵营 / 立场 / 身份 / 主线阶段（数据里有势力、世界、战队等字段时自动出现），星带着彗尾飞到新的扇区，星云随之变形。图谱外是一片深空：斜挂的银河带与暗尘带、几团彩色星云、疏散 / 球状星团、远星系与数万颗点星（每部书一片自己的天，种子 = 书名），整片天绕银极缓慢流转，图谱后方自动压暗 |
| **星盘**（星座的背景） | 顶栏「剧情」或 `P` | 平时在星座外围景深虚化，与星座同一平面；唤醒时镜头对焦、远天轻度失焦，盘面随之升成一只浅碗——细支贴底、支线由内向外逐道升高、主线环与刻度环在碗沿（斜着看层次分明，正视时与平面无异），光环自 12 点顺时针按时间展开：角度 = 回目，弧长 = 这条线跨了多少回。外圈是刻度，主线环按阶段分色，支线在内侧按车道排开（粗细 = 事件数），光珠是事件（关键事件更亮）。悬停一条线 → 这条线的时间扇区亮起、参与者在星座里点亮并连线、卡片列出演员；底部 ▶ 播放 / 拖动 / ←→ 逐回，时间指针带尾迹扫过，刻度条上标着事件密度与主线阶段；弧上有顺时针缓行的流光（时间向前）。左侧是**剧情卡片叠**：按时间排的一叠卡，后一张压住前一张只露标题——主线卡（金色衬线 + 发光脊线）、支线卡（缩进挂在所属主线下）、细支卡（虚线，一段主线下的无名细支合成一张）；点标题展开看全部（时间轨、参与者、关键事件、从这里播放 / 定位），悬停卡片 ↔ 悬停盘上的线双向同步，播放时覆盖当前回的卡标「此刻」并滚到眼前；可筛选主线 / 支线，↑↓ 回车 Esc 操作；窄屏不出卡片叠 |
| **罗盘**（单个角色） | 点一颗星 / 搜索 | 镜头俯冲到这颗星（星爆一闪），远天随之失焦、晶体合焦；中心八维属性晶体（上冠属性八维、下锥叙事八维），悬停轴签出分数与原文证据，水平环绕 360° 时轴签越过晶体中线就在另一栏淡入；外圈关系对象（点谁进谁的罗盘），它们同时作为卫星拖着彗尾走在晶体外的三道星轨上：内轨 亲近（合作 / 亲缘 / 情感）· 中轨 对抗（对立 / 暗线）· 外轨 其他与同场推导；下弧因果事件链（按回排列），几粒暖光顺着时间沿链缓行，入场时事件珠按回序依次点燃。悬停联系对象或事件珠，星轨上对应的卫星同步亮起；`Esc` 返回 |

**操控**：图谱恒在画面中心、不能平移——左键 / 右键拖动、方向键、双指都只做上下左右旋转（星座 / 星盘限在盘面法线 70° 圆锥内，推过了松手回弹；罗盘水平 360°、俯仰 20°–160°），滚轮 / 捏合缩放；星盘态 ←→ 是逐回，Shift + ←→ 旋转；右侧视角栏 俯瞰（正视，最清晰）/ 标准 / 斜视（更立体）/ 环游（绕盘面法线缓慢进动）；双击空白处或按 `R` 复位视角（星座、星盘各有自己的复位机位）；改了窗口大小（包括在星盘 / 罗盘里改的），复位、视角预设、退出罗盘与关掉星盘都按新视口重新取景，星盘态会立即按新盘面重新后拉。

**读取幕**：打开作品（数据链接 / 作品库 / 示例）时先出一张深空读取幕，按真实完成的步骤推进：读取材料 → 推演剧情线 → 排布星座 → 点亮光层（预编译着色器）→ 揭幕。幕上是这部书自己的字符雨（人名 / 回目）、四角发丝准星、五步清单、真实计数的启动日志（逐行打字 + 块光标）、逐字打出带金属掠光的书名与倾斜椭圆彗星轨。幕离场即**线稿构建**：一条自 12 点顺时针的扫掠——极坐标线框（分区环、等距环、辐条、外缘刻度）随扫掠闪现后淡去，星座线在扫掠前沿描出，星紧跟前沿点亮（盘心团最先），组间束丝从一端长到另一端，随后星云、组内关系纤维与深空一起实体化，最后在全书最重的那颗星上点睛（十字芒 + 外扩光环），全程约 2.9 秒；揭幕中途点一下或按任意键一帧到终态（那次点按照常生效）。换书时幕先淡到不透明再重建。系统开启「减弱动态效果」时所有转场一帧到位、循环动效停住（闪烁本身也有上限：星的明暗起伏 ≤ ±8%、慢于 4 秒一周）。画质：星座与星盘在帧率稳住 60 时自动升到原生 4K 画布（3840×2160），一掉帧就退回标准像素上限并隔一阵再试，罗盘固定用标准上限；图上的字是 DOM，始终原生清晰。帧率持续偏低时自动降档：中档降低虚化与星云的渲染分辨率，低档不画事件珠、扫光、星芒、游星与彗尾，星云停止流动；图上的字与可点区域不变。

原书没有关系记录时，联系由事件推导（同一事件同场 ≥2 次），图例里写明「同场 · 推导」，不计入关系数与叙事八维。

「预演」（顶栏）是读图实验室：9 帧故事板（星座 → 星盘 → 罗盘）、读图模式（收字 / 关光 / 灰阶 / 静止）、可分享的深链。

## 材料与分析

- **托盘**：材料可以分批拖入，按批次分组、同文本去重，每个文件可改类型 / 取消勾选 / 移除；点「开始分析」才会开始。
- **规划卡**：文件数 / 字数、类型分布、分块方案、预计耗时、可复用的块缓存；分析过的材料会提示上次的模型与时间。
- **运行中**：进度胶囊常驻，可取消；已完成的块留在 `data/cache/chunks/`，下次续跑不重复付费；断流自动重连到同一作业。
- **重新分析**三选一：补齐续跑 / 全量重跑 / 换模型再跑。
- **作品库**（工具 → 作品库，或 `H`）：分析过的作品全部留档，点卡片重新进入；支持重命名、置顶、导出、删除、排序与搜索。

分析管线（`serve.py`）：短材料单次通读；长材料按章节边界切块并行抽取 → 归并候选 → 别名归并 → 分批建档 → 关系。只依据材料、不虚构；引句与证据必须来自原文，证据不足标 `low`。

### HTTP 接口

| 方法 | 路径 | 作用 |
|---|---|---|
| POST | `/api/plan` | 规划（不花钱）：分块方案、ETA、缓存复用、在跑作业 |
| POST | `/api/analyze` | SSE 分析流；`{docs, force, refresh}` |
| POST | `/api/cancel` | `{job}` 取消作业（已完成的块保留） |
| GET | `/api/jobs` | 在跑 / 刚完成的作业与进度 |
| GET | `/api/history` · `/api/history/detail?key=` · `/api/history/docs?key=` | 作品库列表 / 详情 / 原始材料 |
| POST | `/api/history` | `delete` `open` `rename` `pin` `note` `sweep` |
| GET/POST | `/api/llm-config` | API 档案增删改选 + 连通测试 |
| GET | `/api/health` | 当前档案 / 模型 / 是否配了密钥 |

### 数据契约（graph）

```
title, synopsis,
characters[{name, aliases[], role, importance, identity, brief, traits[], camp, stance,
            attrs{智谋|实力|意志|魅力|情感|野心|权势|道义: {score, evidence[], basis, low}},
            arc[{phase,text}], judgments[{kind,text,chapter}]}],
camps[{name, stance, brief}],
events[{order, chapter, title, summary, characters[], kind, quote}],
relations[{a, b, kind, strength, desc, line:明线|暗线}],
storylines[{id, name, kind:主线|支线|末梢, parent, attach_order, events[order],
            lead, cast[], theme, resolution:收束|悬置|未定, handoff_from, handoff_reason}]   # 可选，缺失时前端推导
```

## 地址参数

## 验收

```bash
sh scripts/accept.sh                                              # 离线契约 + 静态门（CSS 令牌 / 内联样式 / 动效 / 字号 / 脚本清单 / 版本戳）
ATLAS_BASE=http://127.0.0.1:8765 sh scripts/accept.sh --browser   # 再加真浏览器：星空壳、星域、预演实验室、星空光层、镜头、剧情卡片叠、读取幕、揭幕线稿构建、3D 与旋转适配 + 旧版界面回归
CL_GPU=1 python3 -s tests/sky_shell.py --base http://127.0.0.1:8765   # 单跑一套
CL_GPU=1 python3 -s tests/sky_chaos.py --steps 300 --seed 7          # 混沌：3 部书 × 随机操作，每步查不变式，收尾查 GPU 几何 / 纹理不增长（不在 accept.sh 里，约半小时）
```

改了 `js/` 或 `css/` 之后运行 `python3 -s tests/version_stamp.py --write` 重写资源版本戳。测试截图写在工作区外（默认 `/tmp/castline-shots/`，`CL_SHOTS` 可改）。

无头浏览器：`tests/headless.py`（CDP，零依赖）；`CL_GPU=1` 走本机真 GPU，`--eval/--shot` 可连用三段。测试不调用模型、不改 `data/`。
