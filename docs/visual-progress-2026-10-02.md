# 星系视觉升级进度

## 当前阶段

本阶段完成深空、拖动切换和三图谱动效的第二轮升级。目标是保持事实模型、命中区域和降档语义不变，同时提高高档与 4K 设备的材质细节。

## 已完成

- 罗盘关系星拖动记录真实 pointer capture；丢失按键、`pointercancel`、换图谱都会立即取消并清理旧位移、张力线、辉光、缩放和可见性。
- 罗盘拖动期间暂停场景空闲漂移与全局 `scene.aim()`，避免小视口拖动后镜头目标漂移；保持空白区域 OrbitControls 旋转。
- 深空增加分相位燃烧热流、火焰内核、余烬与换态热闪；低档、静止和 reduced motion 会关闭相应循环。
- 体积星云增加旋转域 FBM、多频火焰前沿、射线端点烟丝插值，并把高档体积厚度提升到 0.47。
- Retina / 原生 4K 高档深空立方体贴图升至 768；普通 1440 级仍使用 512。
- 星点加入 Airy 衍射肩、色温高光；远星系加入旋臂、尘带和核球；前景尘埃加入景深流动。
- 年轮增加外环扫光与聚焦弧流光；双晶增加真实多边形路径流光；星域增加灯边涟漪和灯心呼吸。
- 自动质量阶梯加入换书后的 4.5 秒编译缓冲，显式档位保持 5.5 秒，避免开场编译瞬时低帧导致误降档。

## 用户截图反馈：去泛白、保持柔和色彩

用户要求阵营颜色更可分辨，避免灰白，也不要回到早期的硬高对比效果。

- 根因：最终 printGrade 提升中间调亮度后，原色度以绝对值加回，被更亮的灰色底稀释。
- 修正：保持原亮度曲线，按亮度增益有限恢复中间调色度；高光逐渐退出补偿，超色域沿原色相收束。没有增加对比度或压低黑位。
- 同步修正星云瞬时 setState 缺失密度系数的问题，避免切换第一帧更白。
- `python3 -s tests/sky_color_grade.py`：西游记静置和佛门高亮两个场景，通过真实 GPU 同输入 A/B；中间调色差中位数约 2 倍，平均亮度差约 0.00105（0–1 量纲），95%–5% 亮度跨度差小于 0.00025。shader、JS、帧钩子零错误。
- 同帧截图与报告：`/tmp/castline-shots/soft-color/`；佛门高亮：`/tmp/castline-shots/soft-color/hover/`。`scripts/accept.sh` 与资源版本戳通过。

本轮只验收了色彩修正；没有将这些结果作为长时资源稳定性或 30 小时目标已完成的证据。此前 30 步 sanguo / dafeng 轨迹文件记录 `gpuCyclesOK: false`，资源问题仍待核实。
