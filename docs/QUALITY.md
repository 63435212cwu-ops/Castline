## 01 · 用户要求与成品定义

用户要的是：顶级图谱动画特效、前卫且统一的显示审美、高级而好用的交互、可靠的通用小说图谱，以及能把这些目标真正交付的精密计划。每个工作包必须形成用户看得见或内容上可核对的收益。文件数、测试数、运行小时数、节点数和模型调用数均不进入评分。

| 用户要求 | 本计划的落实位置 | 交付条件 |
|---|---|---|
| 删除旧计划、复核要求与评分 | 02、04、19 | 同一路径替换；历史分与当前签收分明确分开 |
| 查清期间做了什么、为何缓慢 | 02、03 | 逐项对到源码、发布物、记录与真实吞吐 |
| 顶级视觉、动画和高级交互 | 05、P4/P5/P6/P7 | 真实页面、完整旅程录像、静帧和独立艺术判断 |
| 无已知重大缺陷的通用小说图谱 | P1/P2/P3、18、20 | 三书全书处置与跨类型样本；错误身份/证据/结果清零 |
| 所有维度100分 | 04、P11 | 八维各自达满分，任一不达标不能用总平均补偿 |
| 项目无多余计划和测试 | P10.7、19 | 责任审计、引用复查、合并后移除，保留必需夹具 |
| 视觉制作占主要投入、下放执行可照做 | 05 | 逐场景构图、108项动效（M01–M108，含参考转译、密图/关系/证据解释、8条完整路径及固定对象施工卡）、明确文件/时长/终态/中断；主线程连续交付，执行者少做自主审查 |

**成品范围。** 三部完整目标作品：大奉打更人、三国演义、西游记。原文范围以实际文件及单元索引为准。通用导入覆盖正文、大纲、细纲、设定、未完稿、分卷、增补材料和版本冲突。不能用三段样片冒称全书完成，也不能把现有三部古典/幻想题材当成任意小说通用性证明。

**显示范围。** 作品库、导入与分析、星座、星盘、人物罗盘、解构、任务旅程、搜索、证据与原文、返回、续读、版本选择、导出。检查静止、旋转、播放、暂停、反拖、切书、窄屏、低档、减弱动态、键盘、读屏、失败和恢复。

**产品方向。** 深空标本馆：小说结构成为可以探索、阅读和解释的天体标本。空间、材质、光影和节奏构成神秘感；明确的阅读层级、连续选择和可靠证据构成高级感。沿用现有HTML/CSS/JS、Three.js/WebGL与Python；模块拆分、worker和缓存只由实际瓶颈驱动。

### 01.1 · 持续 RSI 的实际交付与分工（2026-10-11 用户追加要求）

**主目标是持续新增可操作的图谱动画和交互，并据真实使用结果改进。** RSI 在本项目指“定下一张可见能力卡 → Luna6 制作 → 主线程审图与操作验收 → 修正 → 合入 → 领取下一卡”的持续开发过程；不声称程序能够自行改写模型或无限无人维护。每轮必须交付一个用户能打开、能操作的新增能力或前一候选必要修正，不以扩写计划、增加测试数或刷新报告代替交付。必要修正收口后立即回到新增能力。

**角色固定。** 主线程负责需求、排序、输入边界、审核、真实页面与合并；`gpt-6-luna`（Luna6）负责产品代码与对应责任测试的施工候选。所有实现先在当前源码快照的独占候选目录制作；主线程检查输入哈希后，持合并任务与 GATE 写回。每文件单一负责人、GPU 串行；不得让执行者重新承担计划和独立签收。唯一计划仍是本文，任务队列和检查点仅记录执行状态。

**本 RSI 不新增小说精读、剧情推演或语义审阅任务。** 已发布图谱是展示输入；只检查显示所需的数据契约、身份映射、筛选范围与交互结果。已有另一保留任务及其 `artifacts/` 保持完整。数据缺失显示未知或缺少记录，不制造角色关系、主支线归属、伏笔回收或因果；原文顺序、剧情时间、普通关系、事件同场与因果分别表达。

### 05.3 统一画面语言：照此制作

**总观感。** 深墨空间中的矿物标本与精密天体仪器。大形安静、结构锐利、光源克制；运动由选择、关系和事件引导。材料的厚薄、近远、遮挡和留白形成神秘感。沿用现有颜色语义：暖白正文，矿物青人物属性，紫色时间/叙事层，暖金当前焦点，红色仅用于已定义的冲突类型；阵营沿现有FAMILY取色，不重分配已有语义。

| 画面层 | 具体制作指令 | 不应出现的结果 |
|---|---|---|
| 第一层：当前对象与阅读 | 当前人物/事件的轮廓最清楚；选中标记用短实线环或端点缺口，姓名完整可见；正文落在稳定深墨底板 | 当前对象只有一团白光；白光或纹理穿过正文；hover和已选完全相同 |
| 第二层：直接相关对象与边 | 与当前问题有关的星、轨道和关系完整显示；线先让人看到端点，再提供方向；相关姓名按可用空间展开 | 所有关系同时爆亮；同场关系被画成单向因果 |
| 第三层：群组与全局位置 | 保留中间调云体、群组边界与少量定位名；阅读态可降低装饰光强，但轮廓和全局位置仍在 | 一打开面板整个图谱变黑；通过删除节点或关系降低密度 |
| 第四层：深空背景 | 远星细且稳，中层星尘稀疏；亮云避开主体中心、主要文字与读板；背景饱和度和高光低于数据对象 | 现有左下大亮云继续成为第一注视点；背景星点比人物节点更大更亮 |

**排版固定规则。** 标题使用现有衬线字体，正文沿现有无衬线；新视觉规格只引用现有令牌或在令牌真源新增明确命名值，不在多个文件散写颜色。正文默认16px、可放大到18px及以上；辅助说明12–14px；图中普通可读标签不靠缩到11px以下容纳。段落行距约1.75–1.85；标题和正文之间留一行内距；同组信息紧、不同组信息以间距和细线分开。文字不参与bloom、景深、色散、抖动或逐字闪烁。长姓名换行/侧板全文，不能不断缩字。

**面板材料。** 深墨实底为主，轻微透明只用于外围边缘；1px低亮度边线，一处暖金活动边，不为每张卡都加发光描边。内阴影建立层次，禁止叠多层大模糊。按钮以背景、实线焦点和短位移反馈区分普通/悬停/选中/禁用，主要命中区至少44px。

### 05.4 逐场景施工图

以下以1440×900 CSS像素桌面作为母版；所有位置从当前视口和面板实测尺寸计算，4K保持相同比例与CSS字阶，不把HUD整体缩小。统一使用960px断点，主线程在派卡时列出目前900px等相关消费点并同步改齐。面板转场开始时计算并冻结起止安全区，相机插值到终点；禁止每帧追逐正在移动的DOM重算目的地。小屏使用本节末尾的重排规则。

**S1 作品库与开书。** 画面中上部是CASTLINE与一句现有说明，次层是“打开作品/导入材料”，下面是最近作品。保留作品名和版本说明；近期作品像独立星体标本，各自有可点击的完整书名，不能只剩无文字星点。背景在中心文字区域最安静，边角可有淡星带。hover时只点亮当前作品轮廓，卡片与书名整体上移2px，字号/字距/换行保持不变；点击后这张作品的标题保留到载入反馈，不让用户失去正在打开哪本书的信息。导入/错误/空库沿同一深墨板和字阶制作。

**S2 星座全景。** 顶栏沿当前实际高度固定，默认不压成充满数字的仪表条；左侧目录宽约224px、距边16px，底部控制与图例预留约88px。主图装入剩余矩形，主体轮廓短边约占可用区域的70–82%，中心按可用区域求得，不能固定为全屏中心。云团围绕真实成员聚散形成不同大小与空隙；避免相似花瓣平均环绕。全景首屏主要看清作品、几组群体和少数重要人物，不把所有长标签同时铺满。其余人物仍可搜索、聚焦和展开。未选中态保留一处视觉入口，不能把程序选中的人物伪装为用户已经选择。

**S3 人物选中与关系阅读。** 点击人物后，人物在当前画面中的位置连续移动到阅读安全区中心，不能瞬间跳到另一颗星。右侧读板宽`min(420px,32vw)`，距右边16px；左目录缩成64px导航条，保留展开按钮。图谱取景区域为左导航右缘+24px到读板左缘−24px、顶栏下缘+16px到底部控件上缘−20px。当前对象保留锐利轮廓与全名，直接相邻关系层展开；无关装饰边降到次层，数据星本体仍可见。面板顺序固定为姓名/身份→当前关系或事件→可展开依据，不先堆统计数字。选择另一人物时面板高度不反复弹跳，旧内容淡出后同位置换成新内容。

**S4 人物罗盘。** 上青晶体、中央仪器腰环、下紫晶体构成一个整体，上下实体在光照方向和透射强度上同属一个空间。晶体主轮廓占剩余画布高度约55–68%，上下极值留出至少24px安全距离；属性与关系标签排在两侧安静区域，导线从对应实体边缘伸出，避免穿过晶体正文。腰环是次亮结构，刻度有节奏但不能成为白色锯齿灯带。默认静止就能辨认前面、侧面、厚处与薄棱；旋转用于进一步揭示体积。未知属性保留缺口/待确认提示，不补值、不自动补成对称宝石。选属性只突出该轴及依据；点关系卫星以该卫星为换人线索，姓名、属性、关系同时换到新人物。

**S5 星盘与事件。** 全局时间环为定位框架，当前任务/当前事件为主角。主线、支线、刻度使用不同宽度和明暗，不把多圈叠成同亮金线。当前事件使用有边界的事件珠与短刻线，过去使用较低亮度实线，未来使用轮廓/细线并保留既有剧透限制。阶段长名优先放左侧列表或选中后的说明，不挤在很短的弧段。进入任务后保留一层全书轮廓作为位置参照，只展开该任务真实事件；新增局部展开必须保留真实章节坐标或显示局部放大连线，不能把同章事件挪成虚构时间间距。退出任务恢复原来的全书范围和选择。

**S6 剧情阅读与上下文。** 右侧板分为固定标题、可滚正文、固定主控；标题给当前事件和章节，正文先一句事件，再前因/行动/结果与可展开依据。图谱按S3剩余空间重取景，当前事件与因果两端在可见区域。点击引句进入同板内的上下文页：上方明确“返回事件”，中间保留前后文，高亮真实命中区间，底部显示来源与定位状态。打开原文立即暂停；返回后仍暂停，回到同事件、同滚动位置与原机位（视口变化时按新安全区调整）。现有引句块只能作为入口；上下文取自现存同sourceId/hash的材料，主线程先提供实际读取入口。读取失败在同板显示原因与返回，不清空图谱、不调模型补写。

**S7 搜索、解构、版本、导出及异常态。** 搜索结果每行含对象类型、完整名称和一段上下文，选中后明确高亮对应对象；连续选结果时最后一次有效输入获胜。解构页用一致字阶、分组与留白，内容能滚动、关闭能回对象。版本切换先保留书名与真实状态，装入新图后再做短过渡；没有对应对象时给可读说明。导出面板沿同一视觉系统，导出图保留完整标签和必要图例；此包仅改善已有导出路径，不另开视频制作平台。错误/空数据采用稳定卡片和可操作按钮，不用爆红、震屏或无限旋转掩盖失败。

**S8 窄屏。** 小于960px进入单主面板模式：目录默认收起，右读板改底部抽屉，初始折叠到可辨标题/返回区，展开后默认不超过约48dvh；抽屉可滚动，主控保持可见。图谱中心落在顶栏下缘到抽屉上缘之间，剩余高度不足时优先保持事件/人物及返回入口，次要标签进入列表。顶部标题、底部控制、手势命中区不互盖。横屏或短屏扣除导航与抽屉后图谱可用高度小于240px时，读板改为全屏阅读页并给固定“返回图谱”按钮，关闭后回原对象；不强留两个都读不清的窄区域。旋转屏幕后保留同对象、暂停状态和阅读段落，直接重新取景，不重播开场。触屏没有hover依赖：首次点选显示摘要，明确的“查看”入口进入详情。

### 05.5 材质、云体与光照的明确制作卡

**G1 光照与景深。** 在当前renderer与后处理内统一主光方向：主体上左侧偏冷白主光、后侧偏暖窄边光，下部只留弱紫反射。先保持环境和曝光不变，用实体前/侧面的反射区别建立体量；人物和标签不使用景深模糊。原背景大亮云通过构图避让与局部强度调整退出中心；不能把整幅同时压黑。聚焦/阅读时只降低远景运动和光强，主体中间调保留。复用cosmos的现有状态入口，由主线程给出旧值→新值，不让执行者做无范围参数扫描。

**G2 晶体第一卡：表面先成形。** 主线程把surface/base/core/ghost/waist各自真实消费者交给执行者。先关闭额外内核/ghost装饰的候选显示，保留真实几何和属性读数，制作能看清切面的表面：正面保留中间调，侧面随朝向变深，掠射薄边出现窄亮反射；高光连贯滑过相邻切面，不一片片随机点灯。不新增噪声或更多星点。主线程看三个机位后选定表面，再恢复必要内层；这一步不能由“shader里已有Fresnel”代替可见结果。

**G3 晶体第二卡：厚度与后景合成。** 在G2表面成立后，主线程提供明确实现分支。主路线：对完整闭合晶体取得前/后表面深度，先线性化到同一视空间，再沿视线方向换算几何厚度，以此作为屏幕空间透射近似控制吸收；不得直接相减非线性depth，也不把该近似宣称为完整折射光程；折射只采样晶体后面的场景颜色，内部层经过体积衰减，表面反射单独合成。先做一个晶体，不同时加色散/晶纹。透明后景不能原样穿透厚面，薄棱保留透射；上下两晶体采用同机制而非各自调一串alpha。未知轴导致开口的几何使用已有楔面和表面着色，不对缺失背面求虚假厚度。主线程派卡时必须附近/远面渲染目标格式、线性化函数、视空间厚度换算及场景色采样边界的现成代码片段，执行者只接入指定分支，不自行设计渲染管线。实现不得读取包含自身的场景色造成反馈；切换视图/人物时临时渲染资源随现有生命周期释放。

**G3固定替代路线。** 如果主路线在两个候选窗口内仍有错采样、排序穿插或成本过高，主线程改发“表面反射主导的半透矿物”制作卡：实体大面清楚覆盖后景，内部纹理只在浅层和薄棱出现；保留真实形体、属性轮廓和边缘透光，停止追求全体积玻璃。替代路线要达到S4同样的体量、切面和阅读要求。执行者不得自行在两路线间混合；主线程指定后只做这一条。

**G4 云体。** 沿已有成员密度场，先整理大轮廓：高密区形成厚核、成员间真实空隙形成暗槽、小组保持细小。中层增加少量能随角度看出遮挡的褶皱，边缘薄而破碎，中心不要一团均匀烟棉。近景再加稀疏尘丝；尘丝频率受屏幕尺度限制，远景自动简化。三组形态相似时保留数据事实，通过比例和布局表达差异，不凭书名做火焰/军阵。成员或分组变更时旧轮廓缓退、新轮廓跟随真实成员落位，不将成员数量改小换漂亮。

**G5 星点、关系与仪器。** 数据星保持清晰小核，仅装饰halo随可分辨邻居间距收缩；数据星核与命中区不能一起缩小，重合节点沿现有聚合/展开入口处理；背景星核更弱更小，少数暖/冷星形成纵深。关系束远看聚合，选中后分成能追踪端点的少量主束，完整列表始终可达；关系类别沿现有颜色/线型，只有因果边允许方向传播。仪器环边缘有薄亮芯和暗侧壁，装饰刻度低于章节数字，关闭bloom仍保留结构。高光和颗粒均避开正文与关键数字。

**M97｜双人关系交并对照。** 首帧锁住A/B且排除二人自身；0–120ms分别用单环/双角标识；120–400ms两侧一度邻居在原位描亮；400–600ms共同节点同时带两种标记，读板给共同/仅A/仅B列表。最多6个共同人物前景演示，集合仍完整。统计来自获准范围内的`G.relations[].a/b/id/kind/line`，按normalize后的稳定人物ID去重；先检查aliasIndex及待区分标记，不从事件同场或被截断的`sky-bundles`丝池补关系。无交集写“当前记录中没有共同联系人”，不是“二人毫无联系”。改变关系类型重算最新集合，退出回A/B原位置；减少动态直接给三组列表。落点：`sky-model.js`关系读层、`sky-shell-camera.js`的starScreens及既有读板；**双选入口与集合投影尚需接入**。

**M98｜返回前能认出目的地。** 明确点“最近浏览”或返回旁的预览入口后，0–120ms出现目的地卡边框；120–240ms显示目标作品、人物/事件、视图、筛选摘要与“返回这里”。主图不先移动。确认后复用M09/M21/M24已有恢复路径，只播一次转场；Esc关预览仍在当前位置。记录是当前探索会话的导航快照，**不能把仅存一个锚点的resume假称完整历史栈**；应补有界导航栈（初值最多20项），不保存原文副本或旧画面截图。返回前核对graphKey、稳定ID、阅读边界、任务/事件、视口和滚动；版本已变或对象不再可用时解释原因，不能落到相似姓名。预览不得泄露随后缩小阅读边界已禁止的内容。落点：`sky-resume.js`、`sky-selection-model.js`、既有shell与panel回程。

**M99｜把指向、焦点、选择、当前播放分开。** 指向用细虚线括号，键盘焦点用高对比四角，已选用稳定实线环，播放当前事件沿现有事件珠标记；每次输入120ms内只更新对应状态。多个状态落在同一对象时合并外框并保留必要形状，不叠成白光；落在不同对象时各自保持标签，可展开简短图例说明。键盘移焦不得自动选中，hover不得改变当前事件；只有既有明确提交动作才更新selection/current。失焦撤hover，Esc按层退回，不清空用户已选。落点：`sky-selection-model.js`已区分hover/focus/selection/current，渲染消费需接齐；120ms不是延迟状态写入的timer。

**M100｜歧义关系只展开候选。** 首帧保留原关系声明与确定端点；0–120ms框住多义token；120–360ms读板展开`meta.identity.reviewQueue`或alias队列中实际关联的候选ID；360–520ms标注“候选，未归属”和待核原因。候选在主图只得中性定位括号，不能从已知端向任一候选连出关系。点候选仅查看，不修改身份台账。没有候选ID就保留原token和原因，不做相似姓名搜索补全。与M52共享候选卡外观；落点：`atlas-source.js`已有`ambiguousTokens/attribution`与`sky-deconstruction.js`关系读层，数据规则不改。

**M101｜全书汇总不能冒充此刻。** 0–160ms强调当前关系卡的适用范围；160–400ms在读板显示“全书汇总／限定记录”两个说明槽，当前记录只落其实际声明槽；400–520ms补真实eventIds或范围说明。使用`sky-relation-scope.js scopeOf/of`的现成读层，bookSummary只说明该关系未提供时效限定；atTime也不等于已经核验成立。仅有若干事件锚点时只显示离散标记，**不把第一条到最后一条涂成持续有效区间**；chapterRange也保留其原声明与核验状态。反拖不能让全书汇总关系伪装成即时出现/消失，无时效仍保留范围文字。关闭回原关系，不seek；跳锚点须用户确认并由M58/M13承接。

**M102｜两份事件名单的交并。** 首帧两事件标题与珠固定；0–120ms标左记录，120–360ms标右记录；360–600ms将唯一解析的人物分到共同／仅左记录／仅右记录三组。`events[].characters`缺席不等于没人参与：缺名单一侧标“当前未提供”，不能计算为确定空集。多义人物单列待区分；同名不直接取交集。仅左/仅右表示记录差集，不能演成离场/进场、死亡/新生，线条从人物到事件且无箭头。原图不搬人，前景最多6人，余者完整列表。落点：`sky-shell-player.js`事件参与读层及`sky-deconstruction.js`；复用M85名单与身份解析，不重建人物模型。

**M103｜区间只画成区间。** 0–160ms选中事件旁显示括号形和“原文位置仅知范围”；160–420ms读板展开`sourcePosition.kind=legacy_interval`的源区间条，真实上下界各有可访问名称；420–600ms显示源名、章段、上下界事件入口和“区间内准确位置未定”。采用`start/end/beforeEventId/afterEventId/exactWithinInterval:false`，条中不放中点、不用渐变暗示概率、不把codepoint距离称为剧情时长。边界缺一端画开放括号；unresolved只显示reason和已有章名。未来上界不可公开时隐藏其名称、位置和区间长度，仅说明“当前阅读范围不足以展示完整边界”。主星盘已有排版点不移动。落点：`atlas-source.js sourceAppearanceOrder`及`sky-deconstruction.js`位置说明，原文入口沿M21。

**M104｜来源不同就各有标尺。** 条件是比较项确有不同`sourceId+textHash`，且公开范围内有合法定位。0–180ms来源标签显现；180–520ms说明副本进入独立源栏；520–720ms显示各栏自己的原文位置与“未建立可比顺序”。跨栏不画共享游标、等速扫掠或等比刻度，不按两文件长度归一成故事时间；主图排序保持现有契约。缺sourceId/hash入来源待定区，单源退回M21/M103。读取`meta.sources`和`CLAtlasSource.sourceRefs`；多源时现有sourceAppearanceOrder可能全为unresolved，须使用各条引用的可信本源定位而非强行读全局sourcePosition。**真实多源样本及既有契约夹具未备齐不得签完成**；本轮不创建虚构小说样本。

**M105｜同一事件多状态平行展开。** 0–120ms固定人物与事件双锚点；120–400ms按真实`characterId+eventId`展开状态说明卡；400–600ms按实际`attributes[].name`对齐已有列，保留各记录原值、摘要与依据。消费`characterStateReading().states`中双端resolved记录；文字不同只说“文字不同”，不能自动判矛盾、合并或选择胜者。存在独立reviewIssues时才显示其已记录结论并附范围。只有一条就保持单卡，缺属性显示未提供；身份或事件未解析的记录单列，不能按相近章名合并。换事件清除此组说明；窄屏改上下卡，原图和人物真实属性均不插值。

**M106｜一处引句，多条归属。** 0–180ms固定一处原文引用框；180–420ms展开使用同一完整定位的记录卡；420–720ms以无箭头说明线回连该引用，终帧写“n条记录共用1处定位”。按`CLAtlasSource.sourceRefId/sourceRefs`的sourceId、textHash、offsetUnit、start、end、quote联合身份分组，按层+记录ID去重，不能仅按引句文字合并。逐记录保留语义状态，引用已定位不使任何记录自动已核。缺完整定位仅写“未确认同一位置”，不进入确定复用数。集合覆盖现有events/tasks/relations/characterStates/causeEdges/clues，先过滤阅读范围。点一张记录仍走M75/M21；正文不飞入图，导线也不是新增因果。

**M107｜原文先后与因果方向各守含义。** 0–180ms显示已有因果两端原文章位；180–520ms在读板建立“原文出现位置”和“已记录因果方向”两行说明副本；520–720ms各自静止，原图节点不交换。只有同源同hash且精确定位可比时才写原文先后；同偏移写并列，区间或未定写不能精确比较。因果方向来自已解析`narrativeProjection().causalEdges`的真实端点及类型/依据，推断继续虚线。箭头朝较早出现位置不等于已证实倒叙、回忆或错误；没有故事时间数据不补第三条时间轴。若某端未公开，连其方位与另一行相对关系也不显示。点击原文位置沿M21，不改变播放顺序。

**M108｜状态之间的未知不自动填满。** 0–180ms仅显示获准范围里已定位的真实状态快照；180–420ms在说明列表的相邻记录间加入“中间未提供连续状态记录”的空白分隔；420–600ms将有明确before/after的transition单列，不从两张快照推导变化。此分隔是记录完整性说明，**不是时间长度、概率、失踪或状态中断**；若无可比原文位置，使用离散列表，不画有比例的跨度。两端同值也不能涂满中间区间。已有M65回放仅呈现已声明变化，反拖后不得把未来状态或前一条持有值当当前已知事实。落点：`characterStateReading().states/transitions`、`sky-state-transition.js`及解构状态读层；已存在连续性声明时保留声明来源，不一律盖“未知”。

### 05.6d 成套编排：让多种动画完成同一个阅读问题

本节是M表的使用方法，不另计效果数量。下列时长均为制作初值；读正文、做选择、等待真实数据不计入动画时长，更不能用自动计时替用户翻页。每段只保留一个主解释动作，多个步骤按真实完成通知衔接。界面上以“谁和谁有关”“为什么在这里”“依据在哪里”等阅读入口出现，不显示M编号、技术分层或施工包名称。

**统一的四拍。** 先让用户认出对象，再让用户看见联系，然后读到含义，最后安静停住。默认0–120ms给目标轮廓与即时按钮反馈；120–360ms显示有依据的局部结构；360–600ms补全名、线型说明与依据入口；600ms后只有确有空间交接需要的动作继续，900ms内到静态终帧。M02的1200ms揭幕和M88的960ms解释保留原规格。文字与可访问名称在数据可用时即提供，不能因分镜还没演完而延迟读屏或禁用操作。

| 画面材料 | 使用方法与幅度初值 | 结束后保留什么 |
|---|---|---|
| 焦点轮廓 | 1–2 CSS px实线，120ms显现；一次薄环可收紧≤6px，数据星核不跟着变大 | 当前对象的稳定轮廓与全名；不循环呼吸 |
| 空间交接 | 用同稳定ID的说明副本接住起止位置；沿短路径、无绕圈；相机仍由既有取景者控制 | 真实对象接替副本；删除副本及事件监听 |
| 关系描线 | 普通关系从两端向中间显现，有向因果才沿源→目的；线宽不为吸睛临时变成“更强关系” | 端点、线型、实际方向、类型文字；解释导线不带箭头 |
| 局部拆解 | 普通局部强调的说明副本位移上限24px；M84的分层、M91的候选列及M10的空间交接按各自详细卡与安全区布局，不套此上限；始终有源位置参照 | 展开卡/静态对齐线；原始布局坐标不变 |
| 交并对照 | 左右或上下两区分别显现，在共同项上用同一稳定标记对齐，不靠颜色混合生成第三种含义 | “A独有／共同／B独有”文字和完整列表 |
| 光与材质 | 沿既有光源与相机变化移动窄高光；不在静止对象上随机换面色 | 实面、中间调、边缘与未知缺口；不靠亮度替代数值 |
| 次层退让 | 将装饰退到阅读态档位，数据实体仍可找回；正文和当前标签不模糊 | 主次明确的全局参照，退出按原档位恢复 |
| 状态换页 | 140ms退旧、100ms入新；姓名、正文、依据和ID在同一提交点切换 | 一套一致的新状态；异步旧响应不能补回旧标签 |
| 数量与分母 | 数据已算完才原子显示真实计数；可描亮新计数120ms，不逐个滚数字模拟分析 | 当前显示量、当前范围总量、未计入原因；无分母就直说 |
| 成败与未知 | 成功、失败、未定沿既有类型标记；开放端、虚线、短说明在终帧可读 | 事实状态；不加爆光、彩屑、震动或错误音效 |

**八条连续观看路径。** 每条既是给执行者的镜头脚本，也是主线程的一次真实操作验收。表内箭头表示用户确认后的顺序；停留由用户控制。任一入口缺少所需数据时，就在该处结束为完整静态说明，不借相邻作品或未来章节补镜。

| 路径与读者问题 | 完整画面顺序 | 必须能打断的位置与可核对终点 |
|---|---|---|

| J5 读准时间：“它在什么位置，是否确切？” | M90同章局部展开→M103定位范围→需要时M104跨源分栏/M107顺序说明→M89当前任务停点→M19反拖 | 说明的是源文位置或显示顺序；区间不能收成精确点；跨源不连成统一时间轴；反拖后未来说明全部撤回 |
| J6 对照证据：“同一句话支持了哪些记录？” | M106同引句归属展开→用户点一项记录→M75断言到引句→M21上下文返回→用户确认再读另一归属 | 复用一处引句不增加独立证据数；定位与语义状态分别保留；同句挂接多个记录不等于全都得到语义支持 |
| J7 看人物变化：“同一事件里变了哪几方面？” | M65到一个真实停点→M105并列状态→M12/现有依据卡查看一项→M86读代价→M22/M71结束 | 同一事件的多条记录并列，不人为排出先后；没有明确before/after就保持快照；失败与未定不出现成功收束 |
| J8 小屏与键盘：“能读完，也能回去。” | M95搜索预览→Enter确认→M13真实定位→M23抽屉→M98返回预览→确认返回；Tab/方向键由M37承接 | 390×844和短横屏均能点完整44px目标；软键盘/旋屏直接重排；只移动键盘焦点不偷换选择或播放事件；Esc一层一退 |

**切换与并发只由现有控制者协调。** 以下是要接入的规则，不表示当前已有一个完整动画调度器。复用`sky-motion`的`tween/seq/stagger/cancel/cancelAll/finishAll`及宿主`tick`，结束/取消一组动画按其tag作用域执行；该模块当前没有公开`spring` API。M27/M74需要的阻尼插值只能接到同一个tick，不能凭计划中的“弹簧”另开循环。相机唯一写入者仍是`sky-shell-camera`，播放位置唯一来源仍是`sky-shell-player`。

| 正在发生 → 新输入 | 接续规则 |
|---|---|
| 主解释 → 另一解释 | 撤掉上一次临时图层，从当前实际姿态进入最新解释；两次说明不能并排冒充同一范围 |
| 自动取景 → 拖拽/缩放 | 相机立即让出控制；数据解释可以保持静态，不能定时抢回 |
| 播放 → 打开解释或正文 | 立即暂停语义时钟；关闭解释保持暂停，只有用户继续才恢复 |

## 07 · P1：事件契约、顺序与稳定引用

主要责任：app.js、atlas-source.js、服务端新事件发布入口。复用source/schema/发布合同，不改已发布字节，不擅自重新解释小说。

### P1.1 名称兼容

统计全部事件的title/name/summary/characters，而非只看样例。有效title保留；仅缺失/空白时读有效name；冲突保留原值。两者皆空时显示具名未知状态并提供章节/来源入口，不从摘要杜撰标题，不猜演员。搜索、卡片、播放器和导出共同读取这一边界。

验收：有可用名称却漏显为0；原始值不改；剩余缺名可计数、可定位。负例包括空白、非字符串、超长中文、同名不同ID、恶意HTML、缺演员。草稿中大奉尚有426条确实缺title/name，不能强行刷0。

### P1.2 区分三种顺序

定义原文出现顺序、故事发生时间、因果方向三个独立含义。默认阅读可按原文出现顺序；倒叙、回忆、同时发生只有明确依据才另标。未知位置保留未知，不能因放在列表末尾就被称作结局。图例、文案与播放器必须使用同一语义。

### P1.3 可信源坐标

只接受唯一sourceId、匹配hash、合法codepoint偏移、长度自洽、主引句身份明确且未被quoteReview否决的锚点。不能以JS UTF-16长度代替codepoint。多源或同源不同版本之间不比较offset；同句多处出现不能任取第一处。

验收：精确位置、区间位置、未定位三类分开；错hash、来源冲突、跨源拼接和仅有verified标志的负例不能产生确定顺序。

### P1.4 插入新增事件

保持稳定ID，在同一可信来源内排列已定位事件。无锚点旧事件只有在可信旧顺序及明确同章前后边界夹定时才能保留区间位置，且不得冒称精确。重复order、倒序锚点、无法夹定者进入待定集合，仍可读取。

验收：三国第一回不因追加而排到120回之后；西游黑水河不排在100回结局后；大奉第二百余章不因重复order插到第一章。未定位部分不被伪造全序。

### P1.5 保护旧引用

逐层核对storylines.events/eventIds、attach_order/attachEventId、任务、因果、伏笔、状态、书签和续读。保存原order/rawOrder/原位置映射；跨图身份用稳定ID。显式ID与数字引用冲突必须报告；数字order重复不能择第一条。

验收：重排不换对象、不丢线路成员；归一化两次幂等；app不再二次恢复坏order。负例包括删一条事件、重复ID/order、零/负order、数字字符串和无ID旧缓存。

### P1.6 发布者契约

对新事件规定身份、至少一个可读名称、来源/章节声明及类型；旧缓存继续可读。发布前验证新记录能进入当前读模型，不只检查引句便追加。拒绝候选保留原因，兼容性修订生成新版本，不覆盖原版。

### P1.7 未解决位置的显示

把未知位置、源冲突和错误章标签接入现有证据面。读者能阅读、找依据，但不会被送到虚构时间点。低档和小屏同样保留标记；位置确认数量只能叫定位进度，不能叫语义完成率。

## 08 · P2：来源、章节、身份与分支

### P2.1 来源去重

同ID同hash仅建一份索引；同ID异hash保持冲突；不同ID同文不自动合并。保留文档列表与映射。验收38字符场景：重复导入不得膨胀成3048字符整章，200字符预算仍应包含事件原句。再测空源、同路径不同文、同文不同版和异常编码。

### P2.2 统一章身份

比较源索引、ContextIndex、适配器、sky-model四处边界，使用sourceId/hash和正文范围约束章身份。保留原标签；中文/数字章号仅在卷范围明确时等价。同号跨卷、导航前缀、无空格标题、补发章、附录、感言分别处理。

验收：同事件在三图、补析、原文指向同一章身份。不能为凑120/100/904改边界；原文章节数与事件标签数分开。

### P2.3 五种覆盖分开

分别统计可访问原文、计划窗口、实际接受输入、产出触及、人工语义复核。窗口取并集与补集，携带hash；预算截断按真正进入请求的字符计。重复发送不增覆盖，全部批次完成不显示“全书已理解”。没有金标准的召回保持未知。

### P2.4 四个定位难例

逐条连续阅读大奉“获赠法器”“密信惊魏渊”“戒碑好诗”“龙气之辩”的已取证窗口，分别处理跨章拼接、短句重现/跨卷同号、删去实词、错误章号。先确定错字段再产生新版本候选。

验收：每项有原句、范围、身份和审阅理由；不降全局匹配门限、不猜邻章、不把改写句子标为逐字核验。

### P2.5 人物与称谓

区分正名、专名别称、泛称、职衔、误名、跨代同称。沿“监正/初代监正”等高影响身份检查事件、任务、关系、状态和属性传播。只修已确认错误，泛称歧义保留候选，不以删除全部别名消除问题。

验收：错误归属不会转移分值和剧情；未决人物不被自动补成演员；最近出现的人也不能自动充当匿名发言者。

### P2.6 任务状态

定义completed/failed/blocked/planned/ongoing/partial/缺失的意义。planned不是进行中，partial可能是阶段结果或材料不全，需看记录；缺失不默认成功。保留原状态，中文显示不能改变含义。终局需结果事件和原文，播放结束与任务完成永远分离。

### P2.7 分支对账

固定共同祖先，按ID、范围、角色目标、结论、字段依据比较新增/补证/同义重提取/冲突/范围差异。康平街要对照统一任务与当前四个任务，不能只查ID，也不能按同句去重。

验收：保留、替换、并列、拒绝的理由明确；新版本可追溯；完整目标—阻碍—行动—结果—代价可读；不按时间或节点数自动选“更好版本”。

### P2.8 版本选择与发布

作品库区分原分析、候选、审阅合并版，显示范围与关键缺口。默认选择规则不得等同“事件最多”。打开失败可返回原版；书签/续读仅按稳定身份迁移。发布幂等、冲突拒写，原文和旧版本保持，数据发布串行。

## 09 · P3：全书语义工程

这是内容分数的主线。以连续原文、独立复核和当前页面为交付，不以更多JSON交付。首三批校准与后续全书扩展分别预算。

### P3.1 审阅单元与分母

按原文边界和自足目标划分单元，记前因上下文、当前范围和未读后果。每段有当前处置状态：已审、需上下文、有冲突、非叙事材料、明确未读；状态台账齐全不等于语义完成。排除感言/附录时保留理由与数量，不能剔除难例抬覆盖。台账必须能发现已有事件清单之外的漏段。

### P3.2 事件与遗漏

先确认不可替代的状态改变，再决定事件粒度。人物主张、推理和真正发生分开；不能每句台词都建事件，也不能将多次转变压成模糊摘要。检查错章、漏演员、漏关键行动。出口是独立读者可恢复的重要行动链，数量不是目标。

### P3.3 任务五字段

逐项回答谁要什么、为什么现在、什么阻碍、做了什么、得到什么、付出什么。目标可改变、失败、放弃或被替代。子目标须有独立行动与边界，不按每章配额造任务。

验收：字段各有合适证据，不能同一短引句填满五栏；代价缺席可保持未知，“待验证”不自动叫代价；法律规定不自动叫已执行结果。

### P3.4 主线、支线与跨线依赖

按持续目标和因果依赖识别线，记录开始、挂接、脱离、汇合、移交、解决、悬置。一个事件可属于多线，同人物不等于同线。机械等分只当导航，不计故事结构。

验收：每条线解释为何独立、怎样影响其他线。大奉8段逐步被真实主支线补充；三国/西游也核对跨卷连续性，不因已有34/10条就默认完整。

### P3.5 因果类型和方向

区分直接触发、必要条件、促成条件、人物认为的因果、分析推测和纯先后。每条核对端点、机制与支持。对“归功羊祜→三国一统”等疑点回原文裁定评价、说明或致因，不能给明显错方向边降置信度后继续保留。

验收：相邻、同场、共同演员和“随后”均不足以建立确定因果；反事实只作为审阅问题，不能自动生成事实。

### P3.6 伏笔生命周期

区分铺设、提示、误导、延迟解释、兑现、部分兑现、重启、未回收；跨卷需两端与关联证据。同物件/术语重复不足以构成伏笔。

验收：两端可跳原文；未完稿未回收不等于缺陷。0条提取首先说明缺乏处置证据，不能宣称作品无伏笔。

### P3.7 人物状态与成长

记录能力、资源、身份、目标、立场与代价的真实前后变化；情绪瞬间、旁人评价和稳定人格分开。无前后依据不画成长箭头，不因模型印象加属性分。

验收：罗盘能说明何时、因何变化；可逆/不可逆、原文明示/分析归纳可区分，不能只用星体变亮代表成长。

### P3.8 知情、误信与叙述视角

逐人区分知道、相信、误信、隐瞒、明确不知、读者已知。叙述者全知不能灌给人物；取得信息需事件或明确叙述，沉默不证明知情。

验收：前章回看不会携带后章知识；不可靠叙述和多视角保留分歧，不强行压成唯一真相。

### P3.9 关系随事件变化

亲缘、师徒、同盟、敌对、利用、情感、隐秘关系分别核对范围和变化事件。同场推导维持独立类型。优先审核高影响旧关系，禁止附任意同场引句“洗白”。

验收：三国1539、大奉2106旧关系逐步补证/纠错/待核；罗盘明确展示某时刻关系还是全书汇总，不能混淆。

### P3.10 世界规则、空间与物件

只提取影响行动、资源、约束和后果的明确设定。地点提及≠到达，物件持有/交接/使用/丢失分开；制度宣称、执行、人物误解分开。

验收：规则能解释人物为何能做或不能做，并能回原文。没有依据就不扩出地图、物品链或术语装饰层。

### P3.11 主题、张力与结构解释

主题与张力是解释层，标注分析视角、支撑场景和反例。事件密度、死亡数或时间中点不能自动定义高潮，也不强制套三幕或英雄旅程。

验收：全书概览帮助选择阅读问题；事实与解释可分，多种合理解释可以并列。

### P3.12 独立金标准

从开篇、中段、转折、结局、稀疏支线、跨卷伏笔和身份难例分层抽样。两位审阅者各读原文再标注，之后裁决分歧；候选生成过程不能同时写自己的标准答案。

验收：按事件/任务/因果/伏笔/状态/关系分报精度、遗漏、重大错误和分歧。≥98%/95%是下限，不替代主要任务链逐条审核，不删失败样本提高分数。

### P3.13 校准吞吐并扩展全书

首三批分别选择大奉自足目标、三国因果缺口、红孩儿之外西游一难；记录阅读字符、独立复核、拒绝原因、返工和实际页面成功率。依合格吞吐推算剩余工期。

验收：新增节点多但主要遗漏未减时暂停扩量。模型只替代候选抽取，不能替代审核；无额外API仍可进行原文审阅，不把所有工作误判为停摆。

## 10 · P4：信息架构与三图阅读

主要责任为sky-model、sky-deconstruction、sky-shell系列、卡片、搜索及对应CSS。前置是稳定身份和顺序；语义样本成熟后再关闭端到端门。

### P4.1 每个视图的唯一主问题

星座回答人物/势力如何关联；星盘回答叙事线路怎样展开；罗盘回答单人的特征、关系与轨迹；解构回答目标、因果和证据。分别写明显示什么、编码什么、依据什么、缺失时怎样退化、如何跨图。

验收：同一事实不在四处拥有不同含义。旧年轮/双晶/星域只保留明确兼容入口，不与新用户主流程混杂；切图前读者能预期下一图解决什么问题。

### P4.2 宏观—问题—证据三级

全景优先当前问题和主要群组；聚焦态出现相关人/线/事件；证据态提供完整原文和判断边界。按选择渐进披露，说明折叠了多少信息，并能恢复。不要要求全景同时读上百个标签。

验收：从主问题到原文可沿连续路径到达；稀疏结构诚实显示稀疏，不用装饰伪造丰富；降噪不删除数据。

### P4.3 视觉通道唯一性

登记位置、色相、亮度、线宽、线型、尺寸、运动的含义。一种紫色不能在同一视图同时代表支线、推断、暗线；置信状态用文字/符号补充，不能只变暗。跨视图语义变化必须有上下文与同步图例。

验收：灰阶、关光、静止仍可区分主要结构；图例读取实际编码；通道冲突不能靠删除审计登记清零。

### P4.4 标签和完整名称

保留源名称，场景短标签允许缩写，详情/辅助名称/搜索可取全文。当前、相关、背景对象分别设数量和占屏预算；长中文、重名、单字名、混合字符、极长章名均验证。命中区域与可见对象同源。

验收：当前标签稳定，旋转/缩放不持续抖位；边缘不裁切，单点末章线路有宽度；未知名称不是空白；完整证据不会因省略号失去入口。

### P4.5 选择与跨图恢复

把hover、键盘focus、selection和播放current分开；跨图只传稳定ID及必要视图状态。返回恢复选择、筛选、阅读位置和合理镜头；换书清掉旧引用，不因同名把旧角色映射到新书。

验收：鼠标、键盘、触控可完成同一路径；拖动不会误开罗盘，关闭可逆且焦点返回；异步重绘不会把选择换成第一条。

### P4.6 搜索和版本入口

人物/别名/事件/任务/线路搜索结果显示类型和上下文。无定位结果仍能读并说明原因。作品库显示版本性质、审核范围和关键缺口，数量不作为质量徽章。默认版本规则与P2.8一致。

验收：候选→详情→图谱→原文不换对象；同名作品版本可区分；空结果、损坏缓存、不可用版本都有下一步。

### P4.7 阅读排版与文案

正文、摘要、元信息、证据状态、动作建立固定层级。小屏优先当前内容和主操作，次级工具收纳；关闭和返回保持可达。加载、未提供、待核、定位失败、模型失败分别表达。

验收：没有“所有空值都是暂无数据”；没有工程秒数/原始代码挤占阅读；原文完整且安全转义。未知状态可以降低装饰权重，不能弱化到看不见。

### P4.8 当前生产版本贯通

使用当前三书、缺字段、密集和稀疏样本，逐项走作品→人物→线路→任务→事件→原文→返回；每条加入一次中断或失败。核对标题、身份、来源、状态、章身份在各层一致。

验收：有真实输入和可见结果。VM、公开API驱动、CDP原生输入、人工操作分别标注，不混称全程真实操作。

## 11 · P5：电影级星空、神秘感和材质

本阶段的“电影级”指形体、空间、光学、色彩、构图和节奏统一。复杂shader、透明层数量和炫光不能代替它。主要责任为scene-mats、material-layers、cosmos/nebula/stars/rings/bundles及设计令牌。

### P5.1 视觉准则与观察矩阵

固定每书一个全景、密集区、主角罗盘和剧情事件，以稳定ID登记。固定正视、斜视、侧视和旋转路径，记录相机、曝光、动画时刻与质量档。每帧最多列三个主缺陷，描述位置和影响，如“上晶体前后面无法区分”，不用“高级感不够”代替问题。

建立形体、材质、光照、构图、文字、内容、交互七类观察。每候选只宣称解决对应问题。完整美术母版允许按一张制作卡协调构图、光照、排版；技术参数诊断仍按单机制隔离，避免把完整设计误拆成无穷单参数实验。参考只用于形式和质量分析，不照搬标识、资产或他人作品。字体/资产许可与离线可用性纳入交付。

验收：全幅、1:1细节、连续旋转和真实操作能复现；同一状态能回到基线。缺数据版本、自动掉档、未实际看图、输入漂移时不得做艺术结论。

### P5.2 先修A/B方法

按恢复基线→实际render→抓图→只改一项→实际render→抓图→恢复→实际render→抓图执行。记录真实时钟、相机、uniform、画布、场景帧与渲染器帧，禁止硬写clockFrozen/samePhase。每层都有自己的基线和恢复图。

离线判读独立读取PNG，拒绝仅相信JSON的true。无render、同旧画布、空pairs、无目标材质、无像素信号、错误裁切、恢复失败、跨帧漂移均须失败或阻止相应比较。先只测一个可见晶体层，方法门过了再扩到所有层。

验收：恢复uniform与恢复像素均成立，异常也能恢复；若真实场景时钟或后处理不确定，先定位原因，不能先放宽容差。方法通过只说明可比较，不说明候选好看。

### P5.3 三图构图与观看顺序

为每图确定第一、第二、第三观看对象。先用比例、位置、明暗解决主次，再添细节。星座突出当前人物与相关网；剧情突出当前事件及前后关系；罗盘让身份、读数、关系与晶体相互解释。

灰阶检查后恢复色彩；控制背景亮区与主图/HUD冲突。负空间要承担分组或阅读功能，不能用大黑区隐藏结构。面板展开、搜索、长名、窄屏和手动改机位后都检查安全区。

验收：读者先看到主问题与可操作对象；默认视角和过渡中都成立。删除关系、整体压暗、主体出画或只有截图机位成立的候选退回。

### P5.4 远近星空与星体光学

分开远星场、星团/远星系、近景尘埃和数据星体。用尺度、PSF、亮度与运动构成深度。焦点徽记与周边星光协调，特写不呈贴纸感。随机种子稳定，切书有可解释差异但不每次重随机。

验收：背景有深度却不抢文字；星点不闪烁跳动；低档减少装饰仍保留数据星和命中。运动不改变数据含义。

### P5.5 阵营星云的体积与边缘

低频体负责群组范围，中频褶皱表达密度，高频尘埃承担近景细节；边缘侵蚀、暗尘与空域减少重复棉团。群体形体必须受真实成员分布约束，小组不能膨胀成虚假大势力。

逐项看正视成员可读率、斜视厚度、侧视贴片、旋转连续性和组间混色。用同成员集合/机位做分档比较，不以减少人物换性能。

验收：云体形状可辨，文字/命中不被吞，空域有意义；噪声不只是更细更多，成员迁移时形体变化连续且可中断。

### P5.6 晶体形体与表面响应

隔离surface、volume、core、ghost、waist；暂关内部装饰，在中性光照下检查轮廓、法线、背面、透明排序和穿插。先判宽青面来自几何、混合还是着色，而不是直接调颜色。

分别制作法线响应、反射占比、粗糙度分布的单机制候选。正面、背面、掠射角和连续旋转都检查；高光应随表面方向变化。宽亮边帮助读形，不能盖过面内结构。

验收：不靠说明就能辨前后面；上下晶体与腰环交界清楚。只变明暗、加噪声、改变属性数据改善外形、旋转高光跳动的候选拒绝。

### P5.7 内部体积、厚度与透射

前置是表面候选成立。把透射、吸收、内部散射、核心发光分别可视化；先试路径长度/厚度响应，再试散射分布。内部前中后层在旋转中保持一致空间位置，用结构化测试背景检查折射方向。

内部星点与外部星点不能像叠在同一平面；核心保留中间调，不能洗成整块青/紫。粗糙度、折射、吸收与能量分配共同解释材质，但每次实验只改一项。

验收：厚薄、内部位置、前后层在静止/旋转/暗部成立；纹理不似污渍，背景穿透不破坏阅读；性能成本与收益可解释。每机制最多两轮有效实验。

### P5.8 4K微细节与抗闪烁

检查薄边、细纹、法线扰动、透明叠层和高光的屏幕频率；用导数或带宽限制减少亚像素闪烁，同时保持平均能量与面形。保留旋转录像和1:1裁块，不只拍最美静帧。

验收：无明显moiré、边缘粘连、亮点跳动；中低档削减装饰复杂度，不改评分轮廓。看不出稳定收益的微纹理不合入。

### P5.9 星盘、腰环与精密感

分开主环、支线、事件珠、刻度、阶段色和当前指针。截面与亮芯提供体积，数字与刻度独立亮度预算。金色避免浑浊或死亮；章回净距随密度调整，而不是所有圈同时加亮。

验收：关bloom仍能读结构；正视清楚、斜视立体；过去/当前/未来不只靠颜色；近邻轨道不糊成灯带；末章、单事件、长标题不裁切。

### P5.10 关系束、方向和遮挡

全景可聚合，选中后展开真实端点；因果有方向，普通关系不借因果动势。当前问题之外的线退到次层，可明确恢复。处理穿越星云和晶体时的深度、透明及遮挡，不让细线覆盖所有表面。

验收：密集作品不成发光毛线团；每种线都可被图例解释；聚合能列出真实成员。推断、同场、明确关系不能共用无法区分的样式。

### P5.11 三书差异化

从真实阵营组织、人物网络、任务分支、时间跨度、显式因果选择一至两个有效映射，再扩展。写清每个数据量控制哪种形体/色彩比例/运动节奏、范围和缺失回退。

统一操作和证据语言不变。去掉作品名观察差异，再恢复标签核查差异是否有依据；版本切换后视觉身份应稳定。真实结构相似允许相似，不为“差异”编造火焰、军阵、符箓或文件名硬编码。

验收：差异服务理解，不只是换色；少人物、无阵营、单章节、极密网、缺支线都不失真；直方图余弦只能辅助，不自动判美。

### P5.12 字体、HUD和统一光照

正文/标题/数字/元信息/按钮设字阶、字重、行距和配色。少量衬线标题可强化气质，长正文优先稳定阅读。统一背景、图谱、焦点、文字的亮度角色和光源方向；晶体不能像来自另一套照明。

玻璃底、描边、光晕、bloom和高光滚降一起检查，控制青/紫/金谁占最高权重。神秘感来自尺度、遮蔽和节奏，不来自正文难读。耳机/静音观看都应成立，声音不负责补视觉逻辑。

### P5.13 艺术终审

三书星座/星盘/罗盘九图，补密集近景、侧视、暗部、旋转、阅读态和低档；逐张实际观看。未参与制作的审阅者按同一问题复评，区分明确缺陷和审美分歧。

出口：每个保留候选有可见收益、无关键退步和恢复方案。shader更长、层数更多、像素变化更大、截图分辨率更高都不能单独签收。

## 12 · P6：真实剧情、分镜和可逆动画

### P6.1 真实停点

停点由任务实际引用事件构成，不先固定五段/八站。字段只认明确事件声明或全部引句在同sourceId/hash中的唯一归属。跨源同offset、部分未定位、多事件重叠匹配均保留待定位。

验收：缺字段不造跳转；代价可真实早于结果；复合说明在最后一处必要依据到达后回顾。工程秒数不出现在用户阅读中。

### P6.2 先做静态分镜

对红孩儿、康平街和一条三国样本，逐镜写eventId、当前问题、行动者、人物视野、可显示状态、证据、关注节点、停留条件、暂停/反拖/返回方式。没有依据的环节列缺口回P3。

先关闭所有运动确认故事可读，再决定运动承担指向、连接、转移注意或表达变化。不同任务可不同长度和节奏，不能套固定阶段时长。

### P6.3 目标—阻碍—行动—结果—代价表达

目标锚定行动者，阻碍只显示真实相关对象，行动沿可解释路径，结果点亮真实事件，代价体现资源/身份/关系/价值变化。多次受阻、目标改变、失败和放弃均支持。人物谎言不能演成叙述事实。

验收：每镜增加理解；只是更多粒子/流光的镜头退回。暂停静帧仍能回答谁、为什么、做了什么、改变了什么。

### P6.4 镜头连续与手动接管

规定三图及证据态的机位、安全区和相机恢复。镜头移动必须因行动者或关注点改变，不每事件绕圈。手动旋转/缩放/拖动立即获得控制；恢复跟镜应明确，不自动抢回。

验收：无穿模、突跳和文字出画；改尺寸、退出罗盘和重进剧情按当前视口取景；对象始终可追踪。相同位置不重复追焦，镜头不打断阅读。

### P6.5 因果与关系变化

仅沿已记录边传播，区分触发/条件/推断；无边显示未记录，不自动连相邻事件。关系相变和人物状态动画绑定对应事件，未来变化不能常驻背景提前泄露。

验收：图形、面板和播放器当前eventId一致；没有光束指向另一事件。真实结构不足时回P3，不用动画补剧情。

### P6.6 单一播放状态源

播放、暂停、续播、前后事件、scrub、跳末尾、重播、退出共用一个状态源。反拖撤回未来结果/代价/知识；前因阶段不能借终局引句开场。跳末尾直接落可读终态，不快速演一遍。

验收：不会出现面板在前章、光束在后章、字幕在终局。中途换书清旧计时器；打开原文返回保留对象和进度；播放结束不改任务状态。

### P6.7 载入与氛围动效

载入按实际完成步骤反馈，装饰揭幕可跳过；旧loader退出不等于新遮罩已可点击。hover、选择、星云呼吸、星点闪动使用统一运动预算，循环动效可停。

验收：真实可操作才算可交互；打断落正确终态且不吞首次点击；减少动态不减少结构、证据和操作。

### P6.8 连续录像

每条样本完整录制正常播放、暂停读证据、反拖、手动接管、返回全书、换书；再录减弱动态。记录墙钟、版本和输入方式，不用精选几帧证明完整成片。

验收：状态与录像互证；静帧不签节奏，模拟时钟不签流畅度。用户能理解任务而非仅欣赏光效，才允许动画加分。

## 13 · P7：声场与音画

### P7.1 声音分层

将环境底、操作反馈、事件强调、转场和可选音乐分开，分别规定触发、音量、时长、重叠及停止条件。神秘不等于持续低频轰鸣；电影感不等于所有操作都强提示。资源来源、许可证及离线路径明确。

### P7.2 语义同步

声音由真实事件状态触发，不按固定秒数。暂停、seek、重播、换书停止旧声音；反拖不叠加同一声部。浏览器未解锁音频时不影响阅读，不绕过用户手势。

验收：音画对应同一eventId；声音不晚到造成错误联系；恢复不爆音、不重复，不残留定时器。

### P7.3 静音和长时

总静音、分层音量和持久化清楚；静音时全部语义完整。耳机与普通扬声器检查突发峰值、循环接缝、频段叠加和长时疲劳。重要信息有视觉等价，不能只靠左右声道或音色。

验收：连续使用舒适，后台/系统中断恢复正常；“有配乐”不自动增加剧情表达分。

## 20 · 通用小说适配矩阵与执行咬合

### 20.1 必须贯通的内容类型

| 样本/难例 | 处理规则 | 可见结果 |
|---|---|---|
| 单章/无章短篇、无明确主角 | 真实源区间；允许无主角/少关系 | 安静而完整的图，不凭空生成八条线 |
| 多卷同章号、同名不同人、别名/群体称谓 | 来源+范围+稳定ID，冲突单列 | 不串章、不转移人物属性；用户能看到待区分原因 |
| 倒叙/插叙/并行时间 | 原文顺序、故事时间、播放次序分开 | 同一事件能回原文位置，未知时间不假排全序 |
| 悬疑、谎言、不可靠叙述 | 人物主张、作者叙述、推论、读者已知分别记录 | 视野切换不剧透，反证可追溯 |
| 现实群像、多人目标冲突 | 配角独立目标/行动/代价及跨线反作用 | 不把所有人仅作为主角邻接点 |
| 奇幻规则/世界约束 | 能力、限制、适用范围、违反后果取证 | 规则有出处，推断解释与文本事实分开 |
| 失败/放弃/转向/阶段成功 | 目标达成与事件结束分开，多结果可并存 | 动画结尾不统一庆祝，终局状态与原文一致 |
| 未完稿/开放结局/悬置伏笔 | 已读但开放与未读/漏抽分开 | 未完成是明确作品状态，不能冒称已兑现 |
| 大纲/细纲/设定/正文冲突 | 来源类型与优先依据公开，不静默拼接 | 候选解释并存，可切回对应原材料 |
| 增补/删改/分支版本 | 新键、稳定ID映射、保留/替换/拒绝理由 | 书签/原文/旧版可恢复，冲突不被覆盖 |
| 超密长篇/稀疏材料/超长名/Unicode | 分层披露、明确数量、虚拟化与正确codepoint定位 | 能找到全文与全部对象，低档不丢结构 |

新增类型样本使用可合法使用的用户材料、公共文本或明确标注的合成边界夹具；不为测试调用真实付费模型。通用抽取基准与三书人工精读基准分开，训练/调参样本不得冒充独立验收集。每层分别报告定位精度、断言支持、遗漏、身份冲突和发布可用率。
